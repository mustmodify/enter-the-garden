# Enter the Garden: The Awakening

A photo album from the August 8, 2026 show at The Event Space at Hi-Wire Brewing, Asheville.

Jekyll site for GitHub Pages. Photographs are web-sized renders produced by Storylight from the
photographer's picks; `_data/chapters.yml` lists them by chapter.

Local preview needs Ruby: `bundle install && bundle exec jekyll serve`.

Set `url` and `baseurl` in `_config.yml` to the published address so the link-preview image resolves.
